# 제주멍

실제 제주 산책 영상 위에서 작은 제주 친구와 걷고, 자연 풍경 속 해먹·선베드·패들보드·벤치에서 쉬는 웹 체험입니다.

## 걷기 버전 7 (2026-11-02, be1102b에 포함, 숲길까지 교체 완료)

해안·노을 클립은 60fps 원본을 0.72배로 다시 타이밍한 30fps HLS를 씁니다(`clips.js`의 `slow:true`, 재생 배속 1). 캐릭터 경로는 수동 앵커를 프레임별 카메라 솔브로 실어 나른 30fps 경로(`lab/paths/<clip>-slow.json`)이며, 보행은 발 근처 지면 흐름을 바닥면에 역투영한 이동 거리로 구동하고 디딤발을 2본 IK로 고정합니다. 클립별 태양 방향과 영상 샘플링 조명, 실제 투영 그림자, 캐릭터 레이어 소프트닝·그레인 합성을 적용했습니다. 숲길은 느린 보간 인코딩이 끝날 때까지 이전 방식으로 동작합니다. 측정과 마무리 절차는 `test-lab/04-results/walk-v7/README.md`에 있습니다.

## 쉼터 버전 7 (2026-11-02, be1102b에 포함)

쉼터 배경 4장을 1920 폭으로 올리고(해안 2장은 Swin2SR, 로컬 ONNX) Depth Anything V2로 깊이를 추정해 원·중·근경 3층으로 나눴습니다(`dist/lab/scenes/<scene>/`). `lounge-renderer.js`는 층별 패럴랙스 드리프트, 물·잎·빛얼룩 셰이더, 자리 깊이에 맞춘 층 사이 캐릭터 배치와 해먹 앞 천 컷아웃, 길에서 걸어 들어와 앉고 눕는 입장·퇴장, 장면별 태양과 사진 기반 조명·투영 그림자, 그레인·비네트 포스트를 담당합니다. 산책↔쉼터는 크로스페이드로 전환합니다. 기록은 `test-lab/04-results/walk-v7/LOUNGE.md`.

## 캐릭터 버전 8 (2026-11-02, be1102b에 포함)

돌멍이·귤멍이·구름이·새싹이를 Blender 5.2 헤드리스 스크립트(`test-lab/05-tools/blender/build_companion.py`)로 관절별 부위 메시로 만들어 `dist/assets/characters/*.glb`(각 0.5MB, 정점 색만 사용)로 내보냈습니다. `companion.js`는 기존 관절·IK 보행·자세를 유지한 채 glTF 부위를 관절에 걸고, 로딩 전에는 원시 도형 폴백을 보여 줍니다. 로더는 `dist/vendor/GLTFLoader.js`. 걷기·쉼터에 림라이트를 추가했습니다. 기록은 `test-lab/04-results/walk-v7/CHARACTERS.md`.

## 소리 버전 8 (2026-11-02, be1102b에 포함)

`dist/audio.js`가 Web Audio로 소리를 맡습니다. 걷기는 영상 자체의 현장음을 그래프에 넣어 쉼터와 페이드로 오가고, 쉼터는 사용자 영상에서 잘라 만든 이음새 없는 앰비언스 루프(`dist/lab/audio/{coast,forest}.m4a`)를 씁니다. 발소리는 보행 디딤발 이벤트에 동기해 바닥 재질별로 합성하고, 해먹 삐걱·천 스침·물 찰랑·첨벙·채팅 톡도 합성입니다. 입장 클릭이 언락이며 기본 켬, 걷기 패널의 소리 토글·볼륨과 쉼터 토글이 localStorage에 저장됩니다. 기록은 `test-lab/04-results/walk-v7/SOUND.md`.

## 화면·UI 버전 9 (2026-11-02, 커밋 be1102b로 main 푸시 · Vercel 자동 배포 성공)

`game.css`가 걷기 화면을 풀블리드 스테이지 + 오버레이 HUD(자동 흐림, 바닥 진행선)로 바꾸고, 실험실 요소는 `?debug=1`에서만 보입니다. 입장 화면은 `character-stage.js`의 3D 턴테이블로 캐릭터를 고르고, 세로 폰에서는 스테이지가 화면을 채우며 영상을 좌우 크롭합니다(경로 좌표는 `composite.fit`으로 역변환). 쉼터는 풍경 위 오버레이 툴바·채팅, 머리 위를 따라가는 이름표와 말풍선을 씁니다. 자리 정리 버그(떠나도 자리가 남음)를 `lounge-client.js`에서 고치고 하트비트를 넣었으며, 20분 이상 하트비트가 끊긴 자리는 다른 손님이 비우거나 차지할 수 있는 규칙을 `database.rules.json`에 넣어 사용자 승인 후 배포했습니다(`tools/test-lounge-rules.mjs` 11개 항목 통과). 검수 중 생긴 유령 자리 3석은 정리했습니다. 기록은 `test-lab/04-results/walk-v7/UI.md`.

## 새 코스 2개 (2026-11-02): 노꼬메 능선 · 삼나무숲

`videos/`의 같은 날 60fps 클립을 이어 붙여 만든 코스입니다. 노꼬메 능선(NOKKOME, 2024-07-04 여섯 클립, 126초)과 조천 삼나무숲(CEDAR, 2024-10-24 두 클립, 171초). 길 위치 앵커는 광류 확장 중심으로 자동 추정 후 검수 시트로 손봤고, 나머지(카메라 솔브·30fps 경로·HLS·포스터)는 `test-lab/05-tools/build_course.py`·`auto_anchors.py`·`finish_course.py`로 만듭니다. 절차는 `test-lab/03-analysis/video-catalog/README.md`.

## 코스 흐름 (2026-11-02, v10)

코스가 끝나면 도착 화면에서 8초 뒤 다른 코스로 자동 이동하며, 다음 길로·지도에서 고르기·다시 걷기·쉬러 가기·메인으로를 고를 수 있습니다. `course-map.js`가 촬영 GPS로 제주 지도 핀을 그리고(걷기 화면 오버레이와 홈 화면), HUD와 쉼터에 메인 링크가 있습니다. 새 코스는 `clips.js`에 `map` 좌표를 넣으면 지도에 나타납니다.

## 현재 체험

- 돌멍이·귤멍이·구름이·새싹이 4종을 입장 전, 산책 중, 쉼터에서 선택합니다. 선택은 브라우저에 저장되고 쉼터에서는 다른 접속자에게도 전파됩니다.
- 캐릭터는 Three.js 관절 모델입니다. 보행 주기는 1.9초, 짧은 보폭, 부드러운 시작/정지와 숨쉬기·눈 깜빡임을 사용합니다. 사람 사진 프레임은 현재 체험에 사용하지 않습니다.
- 제공된 실제 산책 영상은 기존 0.72배속을 유지하며 캐릭터 보행을 영상 진행량에 연결합니다. 영상은 촬영 경로를 따라 이동하며 자유 시점 공간 복원은 아닙니다.
- 쉼터는 원래 제공된 바닷가 해먹, 해안 데크, 패들보드, 숲속 풍경 4장을 사용합니다. 격자 가구 배치를 제거하고 사진 속 기존 가구에만 캐릭터를 맞춥니다. 해먹 앞 천은 캐릭터를 가리며, 가구별 크기·각도·앉기/눕기 자세를 적용합니다.
- 바닷가 해먹은 4명, 나머지 구역은 5명입니다. 실시간 자리 점유, 구역별 문자 대화, 만석 시 옆 구역 이동을 지원합니다. 이웃 구역은 같은 풍경을 쓰는 별도 대화 구역입니다.
- 산책 복귀 시 멈췄던 영상 위치에서 이어집니다. 음성 대화는 제공하지 않습니다.

실제 쉼터: `/engine?clip=IMG_0575&room=coast_hammock_001`

가상 배치 확인: 위 링크에 `&loungePreview=5`를 추가합니다. 이 모드는 가상 캐릭터를 명시하고 Firebase에 접속하지 않습니다. 일반 화면에는 실제 접속자만 표시합니다.

## Firebase와 비용

사용자가 승인한 **결제 미연결 Spark `projecthub-97b64`**의 제주멍 웹 앱, 익명 Auth, Singapore RTDB를 사용합니다. 현재 데이터는 `jejumungV6/rooms`입니다. 이전 탭이 마무리될 수 있도록 V5 규칙과 데이터는 보존합니다. 기존 다른 호스팅·데이터는 변경하지 않습니다. `kakaobot-6fea2`는 기존 무료 Analytics 초기화만 유지하며 DB를 추가하지 않습니다.

무료 RTDB 전체 한도는 동시 연결 100개·저장 1GB·월 다운로드 10GB입니다. 구역을 늘려도 전체 연결 한도는 늘지 않으며 한도 초과 시 제한됩니다. 결제 계정, 종량제 초과 사용, 자동 유료 전환, Identity Platform 업그레이드, 유료 API를 연결하지 않습니다. Vercel은 Pro 팀(funjeju's projects)의 포함 전송량 안에서 운영하며, 영상 전송량이 커지면 비트레이트를 낮추거나 영상만 별도 CDN으로 옮기는 것을 검토합니다. 상업 운영과 무료 한도를 넘는 확장은 별도 검토와 사용자 승인이 필요합니다.

관리자 키와 원본 MOV는 배포하지 않습니다. 공개 웹 설정만 브라우저에 포함됩니다. Firebase SDK는 공식 CDN 13.1.0에 고정되어 있습니다.

## 검증과 운영

`npm run check`: 모듈 구문, 4종 모델의 걷기·정지·앉기·눕기, 가구 접점과 자리 수, 영상 HLS, 배포 파일/개인 키 유입을 검사합니다.

`node tools/test-lounge-rules.mjs`: 격리된 V6 QA구역에서 익명 읽기 차단, 타인 자리 덮어쓰기 차단, 6번째 자리 차단, 해먹 5번째 자리 차단, 잘못된 캐릭터 차단, 문자 명의 도용/속도 제한, 동시 자리 경쟁을 확인하고 테스트 데이터를 정리합니다. 일반 사용자 구역에서 테스트 메시지를 쓰지 마세요.

규칙 변경은 `node tools/build-lounge-rules.mjs` 후 `firebase deploy --only database --project projecthub-97b64`만 실행합니다. 이 명령은 기존 호스팅을 배포하지 않습니다.

각 사용자는 최근 5개 메시지를 유지하며, 1.5초 간격을 서버에서 제한합니다. 떠나면 내 메시지를 삭제하며 비정상 종료는 onDisconnect로 정리합니다. 연결 끊김 감지는 지연될 수 있습니다. 공개 익명 쉼터이며 운영자 신고·차단 도구와 대규모 부하 검증은 아직 없습니다.

Three.js r170(MIT), hls.js 1.6.19(Apache 2.0) 라이선스는 `dist/vendor/`에 있습니다. 이번 변경은 기존 풍경과 코드로 만든 모델을 사용하며 새 유료 이미지 생성이나 외부 모델 API 호출은 없습니다.
