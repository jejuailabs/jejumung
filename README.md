# 제주멍

실제 제주 산책 영상 위에서 작은 제주 친구와 걷고, 자연 풍경 속 해먹·선베드·패들보드·벤치에서 쉬는 웹 체험입니다.

## 현재 체험

- 돌멍이·귤멍이·구름이·새싹이 4종을 입장 전, 산책 중, 쉼터에서 선택합니다. 선택은 브라우저에 저장되고 쉼터에서는 다른 접속자에게도 전파됩니다.
- 캐릭터는 Three.js 관절 모델입니다. 보행 주기는 1.9초, 짧은 보폭, 부드러운 시작/정지와 숨쉬기·눈 깜빡임을 사용합니다. 사람 사진 프레임은 현재 체험에 사용하지 않습니다.
- 제공된 실제 산책 영상은 기존 0.72배속을 유지하며 캐릭터 보행을 영상 진행량에 연결합니다. 영상은 촬영 경로를 따라 이동하며 자유 시점 공간 복원은 아닙니다.
- 쉼터는 원래 제공된 바닷가 해먹, 해안 데크, 패들보드, 숲속 풍경 4장을 사용합니다. 격자 가구 배치를 제거하고 사진 속 기존 가구에만 캐릭터를 맞춥니다. 해먹 앞 천은 캐릭터를 가리며, 가구별 크기·각도·앉기/눕기 자세를 적용합니다.
- 바닷가 해먹은 4명, 나머지 구역은 5명입니다. 실시간 자리 점유, 구역별 문자 대화, 만석 시 옆 구역 이동을 지원합니다. 이웃 구역은 같은 풍경을 쓰는 별도 대화 구역입니다.
- 산책 복귀 시 멈췄던 영상 위치에서 이어집니다. 음성 대화는 제공하지 않습니다.

실제 쉼터: `/engine?clip=IMG_0575&room=coast_hammock_001`

가상 배치 확인: 위 링크에 `&loungePreview=5`를 추가합니다. 이 모드는 가상 캐릭터를 명시하고 Firebase에 접속하지 않습니다. 일반 화면에는 실제 접속자만 표시합니다.

## 소스와 배포

GitHub: `jejuailabs/jejumung`, production branch `main`. Vercel: `jejuai/jejumung`, 공개 주소 https://jejumung.vercel.app . `main`에 푸시하면 자동 Production 배포됩니다.

정식 로컬 checkout은 `C:/Users/na/Desktop/vibeproject/jejumong/deploy/jejumung`입니다. Framework Other, Root `./`, Build `npm run build`, Output `dist`, Install 비움. `vercel.json`에 설정되어 있습니다. `npm start`는 127.0.0.1:4176에서 로컬 체험을 엽니다.

주요 파일: `dist/companion.js` 모델/관절 애니메이션, `characters.js` 캐릭터 선택, `lounge-scenes.js` 자연 풍경/가구 접점, `lounge-renderer.js` 사진 위 캐릭터/가림/그림자, `lounge-client.js` 실제 자리/대화. 예전 사람 스프라이트와 15석 자료는 이전 버전 자료로 남겨두었으며 현재 화면은 참조하지 않습니다. 예전 chatgpt.site 공개 버전은 갱신하지 않습니다.

## Firebase와 비용

사용자가 승인한 **결제 미연결 Spark `projecthub-97b64`**의 제주멍 웹 앱, 익명 Auth, Singapore RTDB를 사용합니다. 현재 데이터는 `jejumungV6/rooms`입니다. 이전 탭이 마무리될 수 있도록 V5 규칙과 데이터는 보존합니다. 기존 다른 호스팅·데이터는 변경하지 않습니다. `kakaobot-6fea2`는 기존 무료 Analytics 초기화만 유지하며 DB를 추가하지 않습니다.

무료 RTDB 전체 한도는 동시 연결 100개·저장 1GB·월 다운로드 10GB입니다. 구역을 늘려도 전체 연결 한도는 늘지 않으며 한도 초과 시 제한됩니다. 결제 계정, 종량제 초과 사용, 자동 유료 전환, Identity Platform 업그레이드, 유료 API를 연결하지 않습니다. Vercel도 기존 Hobby 범위를 유지합니다. 상업 운영과 무료 한도를 넘는 확장은 별도 검토와 사용자 승인이 필요합니다.

관리자 키와 원본 MOV는 배포하지 않습니다. 공개 웹 설정만 브라우저에 포함됩니다. Firebase SDK는 공식 CDN 13.1.0에 고정되어 있습니다.

## 검증과 운영

`npm run check`: 모듈 구문, 4종 모델의 걷기·정지·앉기·눕기, 가구 접점과 자리 수, 영상 HLS, 배포 파일/개인 키 유입을 검사합니다.

`node tools/test-lounge-rules.mjs`: 격리된 V6 QA구역에서 익명 읽기 차단, 타인 자리 덮어쓰기 차단, 6번째 자리 차단, 해먹 5번째 자리 차단, 잘못된 캐릭터 차단, 문자 명의 도용/속도 제한, 동시 자리 경쟁을 확인하고 테스트 데이터를 정리합니다. 일반 사용자 구역에서 테스트 메시지를 쓰지 마세요.

규칙 변경은 `node tools/build-lounge-rules.mjs` 후 `firebase deploy --only database --project projecthub-97b64`만 실행합니다. 이 명령은 기존 호스팅을 배포하지 않습니다.

각 사용자는 최근 5개 메시지를 유지하며, 1.5초 간격을 서버에서 제한합니다. 떠나면 내 메시지를 삭제하며 비정상 종료는 onDisconnect로 정리합니다. 연결 끊김 감지는 지연될 수 있습니다. 공개 익명 쉼터이며 운영자 신고·차단 도구와 대규모 부하 검증은 아직 없습니다.

Three.js r170(MIT), hls.js 1.6.19(Apache 2.0) 라이선스는 `dist/vendor/`에 있습니다. 이번 변경은 기존 풍경과 코드로 만든 모델을 사용하며 새 유료 이미지 생성이나 외부 모델 API 호출은 없습니다.
